# 项目整合说明

原有 RAG 学习代码与多轮聊天示例已整理为 `rag_knowledge_qa_system` 下的可运行 Streamlit 应用。

核心链路：

```text
用户问题
  -> 读取当前会话历史
  -> Query Rewrite 生成适合检索的完整问题
  -> Chroma 向量库召回知识片段
  -> Prompt 注入参考资料和历史对话
  -> 大模型生成回答
  -> 展示来源与相关度并保存会话
```

正式入口为：

```powershell
streamlit run app.py
```

检索质量可通过以下命令复核：

```powershell
python evaluation.py
```
